# My_Portfolio

Portfolio de Kheir-eddine Mederreg, Data Scientist. Site statique (HTML, CSS, JS), servi par GitHub Pages.

- Français dans `index.html`, anglais dans `js/main.js` (bouton FR / EN).
- Style « vert acide » (palette Marathon) : vert `#C6FF00`, olive `#A7B800`, bleu électrique `#2F3DFF` en accent, polices Archivo (titres) et Space Mono (étiquettes).
- Effets : preloader, curseur personnalisé, texte mot à mot, heure locale et apparition des sections au scroll dans `js/main.js` ; nuage de points 3D sur canvas dans `js/fx.js`.
- Logos des compétences : SVG de [Simple Icons](https://simpleicons.org) dans `images/logos/`.
