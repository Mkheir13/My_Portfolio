# My_Portfolio

Portfolio de Kheir-eddine Mederreg, Data Scientist. Site statique (HTML, CSS, JS), servi par GitHub Pages.

- Français dans `index.html`, anglais dans `js/main.js` (bouton FR / EN).
- Style « vert acide » : fluo `#C6FF00` sur noir, accents bleu électrique `#2F3DFF` et magenta `#FF2BD6`. Polices Unbounded (titres), JetBrains Mono (étiquettes), Inter (texte), auto-hébergées dans `fonts/`.
- 3D : carte du hero (`images/kheir016.glb`), carte À propos (`images/kheir_data.glb`) et badges (`images/badge_*.glb`), exportés de Blender en glTF + Draco, affichés avec `<model-viewer>`.
- Études de cas dans `projets/`. Ligne de commande sur la touche `/` (`help`, `go <section>`, `lang`, `palette`).
- Grand écran : `js/main.js` zoome la page à `innerWidth / 1536` pour garder la mise en page d'un laptop.
- Effets : preloader, curseur personnalisé, texte mot à mot, heure locale et apparition des sections au scroll dans `js/main.js` ; nuage de points 3D sur canvas dans `js/fx.js`.
- Logos des compétences : SVG de [Simple Icons](https://simpleicons.org) dans `images/logos/`.
