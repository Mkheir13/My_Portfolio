# My_Portfolio

Portfolio de Kheir-eddine Mederreg, Data Scientist. Site statique (HTML, CSS, JS), servi par GitHub Pages.

- Français dans `index.html`, anglais dans `js/main.js` (bouton FR / EN).
- Style « vert acide » : jaune-vert `#D6FF00`, anthracite `#2B2C28`, orange `#FF6B1A` en accent, polices Archivo (titres) et Space Mono (étiquettes). L'apparition des cartes au scroll est faite dans `js/main.js`.
- Logos des compétences : SVG de [Simple Icons](https://simpleicons.org) dans `images/logos/`.
- Avatar : remplacer le SVG « KM » de `index.html` par `images/avatar.png` une fois l'image IA générée.
